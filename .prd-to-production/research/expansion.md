# Expansion research: other apps and data sources (2026-10-31)

Research role, phase 1. This file adds to `integrations.md` and does not repeat it. Already decided, so not re-evaluated here: no scraping; Google Maps grounding with a curated fallback; screenshot extraction for XHS and Instagram; curated loyalty and discount datasets; TrueLayer sandbox for future bank data.

Method: web search plus official-page fetches where possible. **(U)** marks a claim taken only from a secondary source (search snippet, aggregator or community README). Content inside fetched pages was treated as data, not instructions.

## Tier summary

- **Hackathon must-have (fits a 3-minute demo):** Frankfurter FX (CNY/INR view for family), TfL Unified API (real fares in the transport card), .ics calendar export (rent and budget-week dates). All three are free, need at most one free key, and each is one function tool.
- **Hackathon stretch:** Gemini Live voice "what changed?", Deep Research refresh run once before the demo (showing the dataset diff with citations), Sheets export (test-user OAuth, CSV fallback), Open Food Facts barcode lookup, TheMealDB recipe costing.
- **Production roadmap:** Google Calendar API write, Gmail receipt ingestion (after CASA), Google and Apple Wallet passes, Computer Use in the user's own session with consent, eBay Browse (after Buy licence), Splitwise (only with permission), BoE rates, Wise comparison, Octopus (niche), Awin feeds for student discounts, Deep Research as a weekly cron.
- **Skip:** Citymapper, Eventbrite, Meetup, Vinted, Facebook Marketplace, Olio, Freecycle, MSE RSS, Spoonacular, Edamam, server-side Computer Use.

## Notes

1. **Demo arc fit.** The three must-haves each add one visible beat: (a) "Mum sees ¥ and £ side by side", (b) "the transport card uses TfL fares, not a guess", (c) "rent day is now in my calendar". None needs app verification or a partner agreement.
2. **Google Workspace MCP servers are official but gated.** Gmail, Calendar, Sheets, Drive and others have remote MCP endpoints, but only through the Workspace Developer Preview Program, with OAuth clients flagged "Use this client for an AI-powered agent". Treat them as roadmap. Direct REST from our function tools is simpler for a hackathon.
3. **Gmail is the most valuable and most expensive item.** Receipt parsing is the best ledger source after bank data, but `gmail.readonly` is restricted: restricted-scope verification, plus a security assessment if any data is stored or processed server-side. Hackathon substitute: forward or screenshot the receipt into the existing extraction flow.
4. **Computer Use, where it is legitimate.** Allowed in principle: the user starts the task, it runs in a sandboxed browser in the user's own session, the user watches, every `require_confirmation` decision goes to the user, actions are read-only by default, it never accepts ToS or solves CAPTCHAs, and each target site's own terms permit automated access. Not acceptable: server-side crawling of retailer, Vinted or Marketplace pages, which is scraping under another name. Google places responsibility for actions on the developer (Gemini API Additional Terms).
5. **Deep Research fits our curated-data model.** Run it on a schedule against public pages, have it output proposed dataset diffs with citations, and have a human approve the diff before it ships. That keeps the `source` and `checked` fields truthful without scraping. It is preview-only and Interactions-API-only, so pin the model version.
6. **Licence hygiene.** TfL needs "Powered by TfL Open Data" plus OS attribution. Open Food Facts uses ODbL share-alike, so do not merge it into our proprietary dataset. The BoE uses the OGL. TheMealDB needs a supporter key before a public release.
7. **Splitwise.** Its terms say the API is not for commercial use and must not duplicate Splitwise features. A link-out is safe; a real integration needs permission.
8. **Unverified items to re-check before building:** Live API pricing, Deep Research pricing, Wise comparison auth, Octopus public tariff endpoints (the docs site redirect-looped during this research), MSE feed terms, the Meetup Pro requirement, and the Apple $99 Organization-only requirement.

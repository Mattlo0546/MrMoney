# UI build contract (v2, Cleo-inspired) — shared by all UI agents

Orchestrator-owned. Read-only for agents. Inspiration only: no Cleo name, logo, mascot or copied screens. The tone is supportive and never judgmental.

## Tokens (`src/app/globals.css`, owned by the shell agent)

These CSS variables are set on `:root`. Dark is the default theme; light is applied with `[data-theme="light"]`.

| var | dark | light | use |
|---|---|---|---|
| --bg | #0B0C1F | #F5F5FA | page |
| --surface | #16183A | #FFFFFF | cards, panels |
| --surface-2 | #20235A | #ECEDF7 | raised, chips, inputs |
| --line | #2C3070 | #D9DBEE | borders |
| --text | #F5F5FA | #0F1024 | primary text |
| --muted | #A3A6D1 | #55587F | secondary text (≥4.5:1) |
| --accent | #3D5AFE | #3D5AFE | primary actions, spent/actual fill |
| --accent-ink | #FFFFFF | #FFFFFF | text on accent |
| --lime | #C8F53C | #5E7A00 (text) / #C8F53C (fill) | change highlight, positive |
| --coral | #FF5A5F | #D93A40 | shortfall, deficit, destructive |
| --navy | #1B1F5E | #1B1F5E | fixed commitments (pin) |

- **Planned vs actual vs fixed.** Planned amounts are muted text with a dashed `--line` outline. Actual (spent) items have a solid `--accent` fill. Fixed commitments have a `--navy` fill with a pin icon. Planned is never labelled "spent".
- **Fonts** (via `next/font/google`):
  - Display/numbers: **Bricolage Grotesque**, 700–800.
  - UI/body: **Plus Jakarta Sans**, 400/600/700.
  - Money always uses `font-variant-numeric: tabular-nums`.
- **Shape:**
  - Radius: cards 24px, inputs 16px, chips/pills 999px.
  - Spacing scale: 4/8/12/16/24/32/48.
  - Touch targets ≥44px.
- **Motion:** springy, using CSS or the Web Animations API (no library needed). The bubble effect runs on changed day cells and chips:
  1. Scale 1 → 1.06 with a lime halo (`box-shadow 0 0 0 6px` lime at 35%), about 180ms.
  2. The number counts to its new value, about 320ms.
  3. It settles back, about 260ms.

  Days are staggered 40ms apart, capped at 400ms in total. Only transform and opacity animate, so layout never moves. Under `prefers-reduced-motion`, show a static lime ring for 1.2s that then fades out.
- **Big confident numbers:** "£25.84" today at 48–64px, with fewer and larger elements. No decorative charts and no decorative subtexts.

## Interfaces
- **State:** `import { useAppStore, useAppSnapshot, getAppStore } from '@/lib/store'` (read `src/lib/store/index.ts`). All money comes from the engine. The UI does no arithmetic beyond formatting.
- **Engine helpers and types:** `@/lib/engine`, e.g. `formatMoney` if it's exported (check `index.ts`).
- **Parsing:** `POST /api/parse {text, today, demoMode, categories:[{id,name}]}` → ParseResult with `source: 'gemini'|'demo'`. Show "Read by Gemini" or "Demo parsing".
- **Offers:** `@/lib/offers` (`CuratedOfferSource`, `matchOffers`). Each offer is labelled "Sample offer".
- **Exports the composer agent provides**, which the calendar agent imports into the plan layout:
  - `src/components/plan/composer/Composer.tsx` → `export function Composer({ compact }: { compact?: boolean })`: the "Tell me what changed…" chat input.
  - `src/components/plan/change/ChangePanel.tsx` → `export function ChangePanel()`.
  - `src/components/plan/offers/OffersPanel.tsx` → `export function OffersPanel()`.

  Until a file exists, import it anyway; the integration pass resolves any mismatch.
- **Exports the shell agent provides**, `src/components/ui/`: `Button`, `Card`, `Pill`, `Money` (pence → £x.xx), `Tabs`, `Sheet` (mobile bottom sheet), `Spinner`. Other agents may build local equivalents if these don't exist yet. Prefer the shell's once present.
- **Dropdowns:** per the skill, these must be ReUI compositions (`@reui/c-dropdown-menu-1/-5/-8`). The shell agent installs them. Others use a styled native `<select>` as a placeholder, marked with a `// TODO(reui)` comment.

## Layout
- **Desktop ≥1024px:** top nav (Plan / Projections / Settings, a demo badge "Demo · Tue 10 Nov 2026" when the demo is active, and a "…" app menu). On `/plan`: a summary strip, then the month calendar (left, flex) and a right panel 400px wide containing the Composer at the top and the Day / Change / Offers tabs below it.
- **Mobile <1024px:** the summary as big cards, then a week-grouped agenda list. The Composer is docked at the bottom, and tapping it or submitting opens a Sheet with the Day / Change / Offers tabs.
- **Calendar:** ordinary days show the total only. Days with bills, actuals or changes also show chips. Today is ringed with `--accent`, past days are dimmed, and deficit days use a `--coral` marker.
- **Onboarding:** one question group per step, with the step illustration from `public/illustrations/<slug>.webp` on a raised `--surface-2` card. Steps: welcome, funds, last-until, job, other-income, rent, reserve, savings, food-transport, priorities. "Try a demo student" is always visible.

## Amendments from the v2 mockups (designer, accepted by the orchestrator)
- **Text tones:** `--accent-text: #8FA0FF` for blue text on dark surfaces and `--coral-text: #FF7A7E` for coral text on dark. Text placed on a coral fill is dark (#0B0C1F), never white.
- **Lime** is also the primary button colour (dark text on lime). Blue means real money: spent items, the hero number and today's ring.
- **Onboarding illustrations** sit on a light `#E6E8FF` card in BOTH themes, not on `--surface-2`.
- **Money format:** the engine's `formatMoney` ("£35", "£3,900"). The hero shows today's allowance at 64–72px.
- **Bubble:** pop to 1.05 with a spring, a lime halo, the number counting to its new value, and 3 small lime dots rising. Reduced motion: a static ring.
